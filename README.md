# NOCTURNE – BEYOND THE SILENT WORLD (GAMERKIE ORIGINAL)
**Tagline:** *RUN. HIDE. SWIM. SURVIVE. DISCOVER THE TRUTH.*
**NOCTURNE – Beyond The Silent World** is a dark, cinematic 2.5D atmospheric adventure platformer powered by **Three.js**, **GLTFLoader**, custom 2.5D AABB & buoyancy physics, line-of-sight stealth AI, and procedural Web Audio synthesis.
## Features
 * **12 Connected Long-Form Chapters:** Progress from *The Forgotten Forest* and *The Drowned Basin* through industrial watchtowers, flooded transit tunnels, ventilation mazes, and *The Final Facility*.
 * **GLB Asset Pipeline & Fallback Rigging:** Integrates your custom protagonist, 7 distinct enemy AI archetypes, and 12 chapter environment GLBs placed under public/models/, with automatic articulated 3D fallback geometry.
 * **Physics & Environmental Puzzles:** Grab, push, and pull heavy crates onto counterweight pressure plates, operate switches, and unlock hydraulic floodgates.
 * **Underwater Swimming Mechanics:** Buoyancy physics, oxygen management, air pockets, and aquatic pursuit enemies.
 * **Cross-Platform & Static Hosting Ready:** Full desktop keyboard, gamepad, and mobile landscape multitouch controls with localStorage checkpoints.
## Deployment
 1. Upload index.html, README.md, README-EN.md, and your public/models/... folder to a GitHub repository.
 2. Enable **GitHub Pages** in Settings → Pages → Branch: main / (root).
 3. Embed the resulting GitHub Pages URL into Blogger using the responsive <iframe> snippet in DEPLOYMENT_GUIDE.md.
